# Out of Office — a tiny layoff adventure

A cozy, no-clock watercolor office puzzle adventure. Pack a box, rescue a sketchbook, leave a very strange company.

Static site (HTML/CSS/vanilla JS). Run locally:

```bash
python3 -m http.server 8000 -d src
# open http://localhost:8000
```

## Spec-driven development
- `specs/GAME_DESIGN.md` — the designer's doc (what the game is)
- `specs/TECH_SPEC.md` — the agents' doc (how it is built)
- `AGENTS.md` — rules every coding agent follows
- `docs/SETUP.md` — how to set this up in VS Code and Claude Projects
